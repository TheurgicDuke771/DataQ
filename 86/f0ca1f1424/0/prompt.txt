## Design decisions

- **One-time/skip semantics**: gated on `sessionStorage` (`dataq:profileCompletionPrompt:skipped`), not React state — survives a reload of the tab but clears when it closes, which is what "session" means to a user. Closing any other way (Esc/X) counts as skip too; there's no separate "undecided" state.
- **otp mode identity refresh**: in `otp` mode the header name comes from `OtpSessionProvider`'s own captured `/me`, not `MeContext` — so `useSaveDisplayName` also calls the existing `adopt()` (already used by verify) to keep the header in sync. - **Editable in every mode** (Profile page, via antd `Typography.Text editable`): an AAD user's *header* still shows the token's name (untouched), but the stored row — what shares/admin lists render — is now overridable there too.
