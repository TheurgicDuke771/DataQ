**snooze_check**

- **HIGH — a snooze suppresses nothing unless *every* failing check in the run is snoozed.** `alerting/suppression.all_failures_snoozed` returns `failing &lt;= snoozed`; if even one other check in the same suite fails live, the alert fires — and it fires for the whole run, including the snoozed check's failure. The docstring's *"Mute a check's alerts for a while"* and *"only the alert is suppressed"* read as a per-check mute. - **MEDIUM — a snooze never suppresses an operationally-failed run.** `all_failures_snoozed` short-circuits `if run.status == "failed": return False`.
