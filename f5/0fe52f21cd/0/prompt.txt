## Design decisions

**#1138 — fix option 1 (nginx trusts the edge).** `proxy_set_header X-Forwarded-Proto $scheme` sent a deterministically-wrong `http` (TLS terminates at the ACA edge, not at nginx) and *replaced* the edge's correct `https`, so `_cookie_secure()` would have dropped `Secure` on live HTTPS. Chose option 1 over the Terraform env var because it fixes the cause, ships with the image (so BYO deployments get it too), and keeps plain-HTTP local dev working — a hard-coded `Secure` fails *silently*. A `map` prefers `$http_x_forwarded_proto` with `$scheme` fallback across all three proxy blocks; `X-Forwarded-For` verified untouched (the ADR-0035 limiter reads it — pinned by a test). Validated with `nginx -t` through the real image entrypoint. `AUTH_SESSION_COOKIE_SECURE=true` kept as valid belt-and-braces; the docs that described the broken state now describe the fixed one, plus a runbook note that the fix rides the frontend image. No live Azure touched.

**Frontend.** `otp` is checked *before* the OIDC branch so stale `authority`/`clientId` can't override an explicit mode switch. Nothing in JS-readable storage (asserted against the real `Storage` prototype *and* in a browser). Four states — `probing` and `error` both kept off the sign-in form. No invented error taxonomy: the backend's uniform 401 is rendered as-is, with a test pinning that "expired" looks identical to "wrong".

**E2E lane approach.** Both options in the brief turned out unusable as stated: a test-mode hook adds a bypass to a sign-in flow, and a stock MailHog/smtp4dev container can't satisfy `ssl.create_default_context()` (verifies cert *and* hostname) plus AUTH. So the lane brings its own infrastructure, entirely outside the app — an in-repo stdlib SMTP sink (no new dependency, nothing added to pip-audit) emitting a throwaway cert the api trusts via `SSL_CERT_FILE`, plus a second OTP-mode api (required, not preference: the auth seam binds at import time and OTP wins over dev-bypass). Auth mode is injected as `window.__DATAQ_CONFIG__` — the production contract, so no test-only branch in `src/`.
