  - **The sample:** the first 1,000 rows of the first data file, read directly from Parquet one column at a time. Columns are matched by field id, or by name for files without ids, and cast to the schema's Arrow types. If a column can't be sampled (the file isn't Parquet, or it lacks the column), it is priced at 128 Arrow bytes.
