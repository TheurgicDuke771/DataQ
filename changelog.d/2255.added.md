**Every masked sample column now says why.** Beside `redacted_columns`, run detail, the MCP
`get_run_results` / `get_suite_results` tools and every alert channel carry `redaction_reasons`
(same keys): `own_tag`, `inherited_tag` (through column lineage), `policy`, `unclassified`
(fail-closed mode), `detected` (the profiler), `classifier`, or `default_mask` — the column was
never classified, so masking is precautionary. The run page shows the reason beside each masked
column. What is masked is unchanged.
