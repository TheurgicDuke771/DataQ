**The dashboard's result-status figures load faster on a long run history.** Result counts are now kept per suite, hour and status and read from there instead of being counted from every result on each load. At one million results the dashboard summary went from about 385 ms to 246 ms for a 7-day window, and the figures are exactly the same. A new background task runs every five minutes and adds existing history; until it has, those runs are counted the old way, so no number is ever behind.
