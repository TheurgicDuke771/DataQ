**A version in a connection's or check's history can be redacted.** A value pasted into a
config field by mistake and then edited out used to stay readable in the History drawer for as
long as the entity lived. An admin can now redact one connection version, or every version but
the current one, and an editor can redact a check version: the row keeps its number, author and
time, its stored config becomes a tombstone saying who redacted it and when, and a redacted check
version can no longer be restored. The current version is refused — edit it first, then redact
the old one. Each redaction is an audit event naming the version numbers, never the values.
