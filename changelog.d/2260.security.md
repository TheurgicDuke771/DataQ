**Dependency security updates.** `databricks-sql-connector` moves to 4.8.0, which allows
`oauthlib` 4, and `oauthlib` moves to 4.0.0 for CVE-2026-49265 (also published as
PYSEC-2026-4114), a timing side channel in oauthlib's authorization-server PKCE check. DataQ
never runs that code (it only acts as an OAuth client), so it did not reach the product. The connector's new geospatial and
catalog-name-escaping options are opt-in and off by default, so Unity Catalog connections
behave as before.
